# AI Playbook v6.47：拆招操作教程

打开新版 HTML，点击顶栏「教程」。**先练第一套日常流程，再练个人版本；要维护母模板时，再学高级工具。** 系统提供 13 套课程、100 个动作，不要求一次全学完。

## 先用一分钟理解系统

| 你看到的对象 | 实际作用 | 操作后得到什么 |
|---|---|---|
| 系统母模板 | 已整理的可复用方法 | 可选任务和原始来源 |
| 参数中的 [变量] | 每次变化的材料、对象或要求 | 替换进完整提示词 |
| 完整提示词 | 模板与本次参数的组装结果 | 可复制给自己的 AI 工具 |
| 个人提示词 | 你保存并迭代的方法 | 个人记录及历史版本 |
| 候选与策展 | 判断个人方法是否值得入库 | 决定与理由；尚未发布 |
| 内容发布 | 新增或合并当前工作区的母模板 | 内容包及回滚记录 |
| 版本与通道 | 组织内容包、登记身份、设定预览/稳定指针 | 本地治理记录；不是自动生成新 HTML |

搜索、匹配与质量评估是本地规则。系统不会自行调用外部模型生成回答。复制后粘贴到你使用的 AI 工具，再核对事实、遗漏、格式和适用边界；好看的分数和顺利完成练习都不代表模型效果已验证。

## 怎么练：像学一套连招

1. **看一遍**：进任一课程，点「看完整示范」，留意界面变化。示范在另一份样例中运行，不计你的完成，也不改变自己的练习。
2. **拆开做**：选「拆招带练」。每次只看当前高亮控件，按提示点击或填入练习内容。输入后点右侧「检查输入」，点击后等检查结果；做对才进入下一动作。误点可重试。
3. **卡住就专练**：回训练目录，选同一课程与「单个动作」，再选卡住的环节。前置条件自动重放，只把你亲手做的这一步记为完成。
4. **撤掉提示**：同一课程选「独立挑战」。界面不高亮，也不告诉下一按钮；按练过的流程做，填完按 Tab 或离开输入框。需要「给我提示」或示范时仍可使用，但本轮不记为独立完成。
5. **换真材料**：退出训练后，在正式界面用自己的任务做一次。先备份重要个人资料；逐项核对结果。训练记录都是虚构的，不会迁成你的候选、版本或通道。

桌面教练在练习页面右侧；窄屏在页面上方，内容可滚动。点「重练本步」重置样例并重放前置动作；「从头练习」重置本轮。「← 训练目录」或关闭退出。练习复制和导出只生成内部检查内容，正式复制/下载请退出训练再操作。

## 推荐的学习路线

| 这一轮 | 练习 | 到什么程度算掌握 |
|---|---|---|
| 第 1 轮 | 选模板 → 填材料 → 复制指令 | 不看提示能找到参数、完整指令与来源，知道复制后交给谁 |
| 第 2 轮 | 创建个人版 → 编辑 → 比较版本 | 能保存方法、形成旧版、选旧稿看差异 |
| 第 3 轮 | 按需求选择单项高级工具 | 能说明什么时候用、哪个按钮开始、结果改变了哪层记录 |
| 第 4 轮 | 完整连招 | 不看提示能从候选走到内容包、版本登记、预览版与稳定版 |

不要以阅读遍数衡量熟练度。建议同一流程先带练一遍，再独立做一遍，随后更换一份材料在正式界面复做。时间因熟悉程度而异，这不是保证几分钟自动掌握全部治理工具。

## 练习材料

课程中的会议记录是虚构样例：

> 周会决定先校对访谈字幕。小林负责核对人名，周二交付；小周负责整理标题，截止时间尚未确认。短视频方案仍待讨论。

个人版正文保留每次变化的变量：

```text
根据 [会议记录]，为 [阅读对象] 整理决定、待确认问题和行动项。每项行动列出任务、负责人、截止时间与依据原句。未说明的信息写“待确认”，不补造事实。
```

保留“截止时间未确认”和“仍待讨论”，让模型把未知与决定分开，不补造日期或结论。日常课程只练填写会议记录；若还有未填变量，正式复制前应继续填写或明确保留占位符。

## 每套课程的动作清单

下列步骤与内置课程来自同一份动作目录。每行只有一个操作；输入的示例放在每套表格后。前置材料由训练场自动准备，在正式工作区要先具备这些记录。

### 选模板 → 填材料 → 复制指令

组装一次会议纪要提示词，找到来源。

**操作原理：** 系统在本页筛选模板并替换变量；复制后才把指令交给外部 AI，输出仍需核对。

**训练前置：** 空的个人练习区，系统母模板仍在。

| 2 | 点击「会议纪要与行动责任」卡片。 | 模板工作台已打开。 |
| 3 | 点击工作台「02 参数」。 | 现在可以填写本次材料。 |
| 4 | 把右侧虚构会议记录填进「会议记录」。 | 输入已检查，内容符合本步条件。 |

## 十项高级工具：什么情况下才用

| 工具 | 什么时候用 | 实际结果与边界 |
|---|---|---|
| 控制中心 | 想知道先处理哪些治理问题 | 汇总数字，点击回原工具；不会处理问题 |
| 候选母模板 | 个人方法已经试用，准备进入母模板评审 | 提交、接受/暂缓/驳回；接受不等于发布 |
| 版本发布 | 已有正式内容包，需组织版本和通道 | 登记与通道会改变本地治理状态，不能当作 HTML 交付 |
| 审计追溯 | 问“这张卡来自哪里、经过哪些决定” | 看上下游关系；不自动补来源或认证原创 |
| 质量观测 | 保存结构基线或核对退步 | 指标、快照和变化；不是模型效果测试 |
| 发布策略 | 需要判断允许、需审查或阻断 | 策略/审计与执行计划；预演不推进通道 |
| 治理模拟 | 先比较“如果这样改会怎样” | 假设指标结果；正式数据不随模拟改变 |
| 治理洞察 | 不知道告警意味着什么、去哪核查 | 证据与建议、返回原工具；不自动修复 |
| 人工审查 | 需要人对事项或例外作决定 | 状态与决定历史；真实关联批准可能恢复编排 |
| 修复计划 | 策略阻断且需要补齐条件 | 修复路径和复检；没补事实仍会阻断 |

人工审查课程用于练状态转换；其中来回切页并不等于已经补材料。真实事项必须先核对所需证据，再批准。修复课程刻意保持缺失回滚点，教你识别“仍阻断”；真实解除需要回原流程补齐回滚事实后复检。

## 卡住时先核对这些

| 现象 | 原因或下一操作 |
|---|---|
| 填完没有继续 | 带练点「检查输入」；独立模式按 Tab。对照当前字段与要求，别把文字填到另一字段 |
| 点了按钮仍停在本步 | 看反馈：动作之外还要得到指定结果；禁用按钮先核对前置门槛 |
| 看完示范没有已完成 | 示范不计亲手操作，关闭后回自己的练习做一遍 |
| 旧稿没有“与当前 内容差异” | 当前稿不能与自身比较；先选择历史 v1 |
| 模拟看起来通过但正式发布仍阻断 | 模拟是复制指标上的预测；去正式工具补真实证据 |
| 复检仍阻断 | 复检不自动修复；本练习故意缺少回滚点 |
| 想把训练结果带回正式库 | 退出后用自己的素材复做；练习数据不能当真实评审证据 |
| 提示进度未保存 | 本次动作仍可练习，但刷新后进度可能丢失；确认浏览器允许本地保存 |

## 如何把教程跟着功能维护

新增或改动按钮时，同步改动作目录里的目标、输入、检查、成功说明和原理，并运行动作门禁。更新帮助、教程版本和 Coverage、开发日志的全部/功能/Bug/内部验证/时间线/复盘、release.json 和配套文档；重建并核对交付 HTML。

本版继承 v6.46 的 79 张母模板、18 类与 6 个主题。来源广场有 1,350 条记录；历史 sources=2,550 是旧汇总口径，两者不是同一统计。本版没有改写来源正文、署名或原始母模板数据。
