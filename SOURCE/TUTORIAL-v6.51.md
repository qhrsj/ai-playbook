# AI Playbook v6.51 / P73 · 本地个人使用教程

系统帮你找模板、填材料和保存自己的提示词。填写后复制完整指令，粘贴到自己使用的 AI 工具，才会得到回答。浏览、检查或收藏都不会自动运行 AI。

本版工作区有五个日常页面，以及两个需要时才用的辅助操作。以前十项发布维护工具的操作界面和运行逻辑已移除；旧记录继续随完整备份保留。升级不会自动清空个人资料。

## 第一次只学三件事

1. **找一个能用的模板**：主页输入关键词筛选并亲手打开卡片；不知道名称时点匹配模板，先看推荐再进入。
2. **留给下次用**：点☆ 收藏保存入口；想长期修改，点存成我的版本，在编辑器保存提示词。
3. **复制前和改动前**：需要查遗漏时用检查提示词；重要修改或换设备前下载完整备份。

## 当前界面怎样找入口

主页左侧上行显示系统名称与版本，下行是主题副标题。右侧十二个按钮按等宽网格排列；宽屏六列，窄屏四列或三列，手机继续显示名称。按按钮名称找功能即可。以前保存的自定义顺序仍然有效；拖动或 Alt 加方向键调整，右上角的 ↺ 只恢复按钮顺序。

我的工作区先看五个日常标签。标签旁标有“辅助”的两个小按钮分别是检查提示词、备份与恢复。空间不足时它们会放到下一行；手机保留较大的触控高度。点按钮切换内容，不会运行AI，也不会自动修改或恢复资料。

使用教程的卡片目录与“要学什么”下拉选项来自同一份当前课程数据，按主界面入门、日常操作、检查整理与备份分组。本版没有旧高级工具的空标题；检查、整理、备份各有可以点开的模块卡片。先读模块目的，再开始练习。旧版本的手册和日志只供追溯，操作以本版使用教程为准。

## 工作区各页面

| 页面或操作 | 什么时候用 | 操作与结果 |
|---|---|---|
| 我的提示词 | 长期保存自己的写法 | 新建/导入/存成我的版本 → 保存；修改会保留旧版本 |
| 收藏 | 下次快速找到好用的模板 | 主页、详情或来源广场点☆ 收藏；打开原对象或删除收藏关系 |
| 最近使用 | 找回刚打开的模板 | 打开会记录；删除只移除历史，再打开重新记录 |
| 随手记 | 想法还没形成完整提示词 | 写随手记 → 保存为记录；成熟后转成我的提示词 |
| 回收站 | 找回误删的提示词或随手记 | 恢复找回整条记录；永久删除需确认且不可恢复 |
| 检查提示词 | 复制前看看有没有遗漏 | 选一条/粘贴正文 → 开始检查 → 按清单修改 → 保存修改 |
| 备份与恢复 | 换设备、重要修改或误操作后 | 下载完整JSON；选择旧文件 → 核对预览 → 确认恢复 |

我的提示词直接显示打开、修改、检查和旧版本。“更多”里放复制一份、收起暂不用的、删除到回收站。默认看可用和草稿；收起后在状态筛选选已收起，更多 → 重新启用可找回。

旧版本只恢复一条提示词内容，并保留恢复前版本；完整备份恢复会替换整个工作区。复制一份/存成我的版本先进入编辑器，保存前还没有新增提示词。

## 两个辅助操作的原理

检查提示词逐项找文字线索：正文、任务要求、可替换材料、输出形式、缺失信息处理。没有变量或严格格式也可以使用，按任务决定。它不给效果总分、不联网、不代跑AI、不自动保存。正文改变后旧清单失效，需要重新检查；保存修改进入编辑器，保存提示词后才更新记录和保留旧版。

完整备份先等待最近保存完成，再生成JSON，包含个人提示词、收藏、最近使用、草稿/随手记、回收站、设置、教程进度和旧版本兼容记录。只导出我的提示词用于通过导入文件追加个人模板，不能恢复整个工作区。

选择备份文件只读取和预览。先核对文件名、日期、数量及替换范围；要保留当前资料先下载一份新备份。取消不改变现有内容，确认恢复才替换并重新载入。损坏、过新或保存失败会停止并提示。以前的归零前副本仍可在备份页导出，恢复它会带回旧记录。本版启动不自动归零。

## 手把手练习

任意主题顶部点使用教程，先读作用、目的、原理和准备条件。共 9 个模块、169 个环节：130 个实际操作与 39 个观察。

建议顺序：主界面 → 筛选或匹配 → 收藏 → 我的版本 → 检查 → 整理与回收站 → 备份恢复。来源广场按需要学习。

每次只做一个动作。输入时右侧示例框和复制按钮高亮，亲手粘贴到左侧；填写后检查输入，成功后核对真实变化再继续。下拉项直接选择，不需要复制文字。结束明确告知完成，清除高亮和注释，点完成并退出。

训练使用隔离的虚构个人资料，不读取或改动正式工作区。示范不计亲手完成，单步练习会说明自动准备前置。备份在虚拟文件区：点击“练习：载入刚才的虚拟备份”只代替文件选择，预览、取消、确认仍走同一恢复处理器。正式页面没有这个练习按钮，须通过真实文件选择器选择JSON。永久删除只观察入口，不要求执行。

教程默认最大化，可还原拖动缩放；窄屏上下排列。注释放不下时移到说明栏，避免挡住操作。筛选、需求匹配、来源分页和回链按真实按钮进行，不直接替你跳转。

## 各模块逐步清单

### 主界面与每个按钮的用途

**作用与目的：** 认清主页每个入口，能判断自己的任务从哪里开始。

**适用时机：** 初次打开、不知道从哪里开始。

**操作原理：** 主页是导航与检索；阅读介绍不会替你执行业务操作。这个模块逐个高亮入口并解释作用，点右侧确认继续。 顶栏标题和版本放在左侧，功能按钮按等宽网格排列；窄屏自动增加行数，名称继续显示。用户保存的按钮顺序仍有效，以按钮名称识别入口。

**准备条件：** 不需要个人记录；此模块只观察说明，不代点按钮。

**学完会做什么：** 能区分搜索、需求推荐、个人资产、来源与设置入口。

**操作边界：** 训练与正式工作区隔离；示范与自动准备不计为亲手完成。本模块仅观察入口，实际执行另选操作课程。

### 需求匹配 → 填材料 → 复制 → 回查来源

**作用与目的：** 把需求提交给本地推荐，再亲手选模板、填写材料、复制指令和核对来源。

**适用时机：** 知道想完成什么，希望系统推荐适合的方法。

**操作原理：** 输入只筛选主页；点击匹配才显示推荐。需求导航会把需求文字带入一个参数，但它不是完整会议材料，必须核对并替换。

**准备条件：** 正式操作须准备真实会议记录；训练只使用虚构记录。

**学完会做什么：** 亲手从推荐进入模板，替换材料并复制；能回查三条来源。

**操作边界：** 训练与正式工作区隔离；示范与自动准备不计为亲手完成。先做真实动作，再看实际变化；不能把完成训练当作模型效果或真实发布已通过。

| 步骤 | 亲手操作或观察 | 为什么做 |
|---|---|---|
| 1 | 在主页长搜索框输入「会议纪要」。 | 先看下面的筛选结果；还没有进入需求导航，也没有生成 AI 回答。 |

| 11 | 返回「我的提示词」。 | 检查后的记录仍属于自己，不进入发布审批流程。 |
| 12 | 点击这条记录的「旧版本」。 | 查看保存之前的版本，确认旧正文没有丢失。 |
| 13 | 点击最早的旧版本。 | 选择历史记录后才可以比较；当前版本不需要和自己比较。 |
| 14 | 点击「与当前比较」。 | 高亮增删文字，核对你到底修改了什么。 |

### 备份 → 核对 → 取消或恢复

**作用与目的：** 给个人资料留一份可带走的副本，学会恢复前先核对，避免选择错误备份就覆盖当前内容。

**适用时机：** 换设备或浏览器、重要修改前，以及误删后想回到某个备份状态时使用。

**操作原理：** 完整JSON保存工作区；选择文件只打开预览，取消不写入，确认恢复才替换。训练下载使用虚拟文件区和同一恢复处理器。

**准备条件：** 训练场提供一条虚构提示词。正式恢复需要以前下载的完整工作区JSON；仅导出提示词的文件要通过导入文件追加。

**学完会做什么：** 能下载完整备份和单独提示词，识别两者差别，核对记录数量、取消恢复，并找回训练场刚删掉的记录。

**操作边界：** 恢复是覆盖，不是追加；确认前先备份当前资料。练习的虚拟文件按钮只存在训练场，正式页面用选择备份文件和真实文件选择器。

| 步骤 | 亲手操作或观察 | 为什么做 |
|---|---|---|
| 1 | 打开「我的工作区」。 | 备份针对自己的整个工作区。 |
| 2 | 点击「备份与恢复」。 | 先看备份与恢复的区别，以及当前记录数量。 入口是工作区标签旁“辅助”一栏的小按钮，窄窗口会换到下一行；按名称找到它即可。 |
| 3 | 点击「下载完整备份」。 | 训练场在虚拟文件区生成完整JSON；正式使用会下载文件，需要自己保留。 |
| 4 | 点击「导出我的提示词」。 | 这份文件只含提示词，适合单独导入；完整工作区恢复要用上一份备份。 |
| 5 | 观察正式页面的「选择备份文件」入口。 | 正式使用：点击后在文件选择器选完整JSON，再看预览。本练习不用真实文件，下面明确使用虚拟副本。 |

| 9 | 返回「备份与恢复」。 | 当前我的提示词已变成零条，但刚才的完整备份仍有一条。 入口是工作区标签旁“辅助”一栏的小按钮，窄窗口会换到下一行；按名称找到它即可。 |

### 收起、回收站与旧版本

**作用与目的：** 用容易区分的操作整理自己的提示词：暂时不用先收起，误删到回收站恢复，改错内容可找旧版本。

**适用时机：** 自己的提示词越积越多、想收起不用的，或发现误删/改错一条记录时使用。

**操作原理：** 收起只是状态变化；删除到回收站保留整条记录与版本；恢复旧版本只修改这一条，并保留恢复前的版本。

**准备条件：** 训练场提供一条虚构记录与旧版本，不读取用户的私人资料；筛选默认只看可用与草稿。

**学完会做什么：** 能收起和重新启用、删除到回收站与恢复，以及查看并恢复单条旧版本。

**操作边界：** 永久删除需要确认且不可从回收站恢复。本课程只观察这个入口，不要求永久删除；它与恢复完整工作区不同。

| 步骤 | 亲手操作或观察 | 为什么做 |
|---|---|---|
| 1 | 打开「我的工作区」。 | 整理自己的记录不需要模板库发布工具。 |
| 2 | 展开练习记录的「更多」。 | 次要动作集中显示，先读名称再操作。 |
| 3 | 点击「收起暂不用的」。 | 记录从默认可用列表收起，没有删除正文或旧版本。 |
| 4 | 在状态筛选选择「已收起」。 | 收起的记录仍保留，通过筛选即可找回。 |
| 5 | 再展开这条记录的「更多」。 | 已收起状态下提供重新启用。 |
| 6 | 点击「重新启用」。 | 恢复可用状态；当前筛选只看已收起，所以记录暂时离开这个列表。 |
| 7 | 把状态筛选改回「可用和草稿」。 | 回到日常列表，核对记录仍在。 |
| 8 | 展开「更多」，准备练习删除。 | 删除进入回收站，和暂时收起不同。 |

| 12 | 点击这条记录的「恢复」。 | 找回整条提示词与保存过的版本，回收站移除它。 |
| 13 | 返回「我的提示词」。 | 找回的记录可以继续使用。 |
| 14 | 点击这条记录的「旧版本」。 | 内容改错时，不必恢复整个工作区，只需选择这一条的旧版本。 |
| 15 | 选最早的旧版本。 | 先核对版本日期和正文，再决定是否恢复。 |

## 常见卡点

| 现象 | 处理 |
|---|---|
| 收起后找不到 | 状态筛选选已收起，再更多 → 重新启用 |
| 检查后原记录没变 | 检查只给线索；保存修改后，在编辑器再保存 |
| 修改正文后清单消失 | 旧清单已失效，重新检查 |
| 收藏打开来源广场 | 这是原文收藏，保留署名，不是母模板副本 |
| 文件选完没有恢复 | 先核对预览，再点明确的确认恢复 |
| 提示不是完整备份 | 单独导出的提示词通过导入文件追加，完整恢复用工作区JSON |
| 找不到以前发布工具 | 本地个人版已移除，旧记录仍随完整备份保留 |
| 训练没有真实下载 | 练习用虚拟文件区；退出教程后再进行正式下载 |
