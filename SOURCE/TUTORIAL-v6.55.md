# AI Playbook v6.55 / P77 · 本地个人使用教程

这里帮你找模板、填材料、保存自己的提示词。填好后把完整指令复制出来，粘到你平时用的 AI 工具里，才会得到回答。只浏览、检查或收藏都不会自动运行 AI。

这一版的工作区有五个日常页面，外加两个需要时才用的辅助操作。以前那十项发布维护工具已经从界面和逻辑里移除；旧记录仍随完整备份保留。升级不会自动清空你的个人资料。

## 第一次只学三件事

1. **找一个能用的模板**：在主页输入关键词筛选，亲手点开卡片；不知道名字时点「匹配模板」，先看推荐再进入。
2. **留给下次用**：点 ☆ 收藏存入口；想长期改，就点「存成我的版本」，在编辑器里保存提示词。
3. **复制前和改动前**：怕有遗漏就用「检查提示词」；重要修改或换设备前，先下载一份完整备份。

## 当前界面怎样找入口

主页标题区按文字实际需要占宽，名称和版本下面留着简短副标题。右侧十二个按钮挨着标题；够宽时排一排，窄一些就分成六列、四列或三列，手机上继续显示名称。按按钮名称找功能就行。拖动时邻近按钮会平滑让位，松手回到原位；以前保存的顺序仍然有效，也能用 Alt 加方向键调整，↺ 只恢复顺序。系统开启「减少动态效果」时，这些位移动画会关掉。

打开「我的工作区」，先看五个日常标签。标签旁标着「辅助」的两个小按钮是「检查提示词」和「备份与恢复」。空间不够时它们会换到下一行；手机上保留较大的触控高度。点按钮只是切换内容，不会运行 AI，也不会动你的资料。

使用教程的卡片目录和「要学什么」下拉来自同一份当前课程数据，按主界面入门、日常操作、检查整理与备份分组。这一版没有旧高级工具的空标题；检查、整理、备份各有点得开的模块卡片。先读模块目的，再开始播放。旧版本的手册和日志只作追溯，操作以本版使用教程为准。

## 工作区各页面

| 页面或操作 | 什么时候用 | 操作与结果 |
|---|---|---|
| 我的提示词 | 长期保存自己的写法 | 新建/导入/存成我的版本 → 保存；修改会保留旧版本 |
| 收藏 | 下次快速找到好用的模板 | 主页、详情或来源广场点 ☆ 收藏；打开原对象或删除收藏关系 |
| 最近使用 | 找回刚打开的模板 | 打开会记录；删除只移除历史，再打开重新记录 |
| 随手记 | 想法还没形成完整提示词 | 写随手记 → 保存为记录；成熟后转成我的提示词 |
| 回收站 | 找回误删的提示词或随手记 | 恢复找回整条记录；永久删除需确认且不可恢复 |
| 检查提示词 | 复制前看看有没有遗漏 | 选一条/粘贴正文 → 开始检查 → 按清单修改 → 保存修改 |
| 备份与恢复 | 换设备、重要修改或误操作后 | 下载完整 JSON；选择旧文件 → 核对预览 → 确认恢复 |

我的提示词直接显示打开、修改、检查和旧版本。「更多」里放着复制一份、收起暂不用的、删除到回收站。默认看可用和草稿；收起后在状态筛选选「已收起」，再进「更多 → 重新启用」就能找回。

旧版本只换回一条提示词的内容，并保留恢复前的版本；完整备份恢复会替换整个工作区。复制一份、存成我的版本会先进入编辑器，保存前还没有新增提示词。

## 两个辅助操作的原理

「检查提示词」逐项找文字线索：正文、任务要求、可替换材料、输出形式、缺失信息处理。没有变量或严格格式也能用，看任务决定。它不给效果总分、不联网、不代跑 AI、不自动保存。正文改过，旧清单就失效，需要重新检查；点「保存修改」进入编辑器，保存提示词后才更新记录并保留旧版。

「完整备份」先等最近的保存完成，再生成 JSON，包含个人提示词、收藏、最近使用、草稿和随手记、回收站、设置、教程进度和旧版本兼容记录。只导出我的提示词用于通过导入文件追加个人模板，它恢复不了整个工作区。

选择备份文件时只读取和预览。先核对文件名、日期、数量以及替换范围；想保留当前资料就先下载一份新备份。取消不改变现有内容，只有确认恢复才替换并重新载入。文件损坏、过新或保存失败都会停下并提示。以前的归零前副本仍可在备份页导出，恢复它会带回旧记录。这一版启动不会自动归零。

## 视频式使用教程

在任意主题顶部点「使用教程」，先读作用、目的、原理和准备条件。共 9 个模块、159 个环节，演示 130 个操作和 29 个观察位置。

建议顺序：主界面 → 筛选或匹配 → 收藏 → 我的版本 → 检查 → 整理与回收站 → 备份恢复。来源广场按需要观看。

点「开始播放这节教程」，画面会自动操作真实界面。左侧只留演示画面，右侧集中当前解说、进度、暂停/继续、重播、镜头切换和播放速度旋钮。手机上同样保留右侧控制区。你不需要一步步点业务按钮，也不用反复确认。

默认跟随镜头：当前框选的位置和操作结果会移到画面中部；点「镜头：跟随」切换全景，完整演示视口会按可用区域缩放。演示里的注释不盖住画面，当前用途与目的在右侧阅读。系统开启「减少动态效果」时会关掉镜头位移过渡。

速度旋钮从 0.5 倍到 2 倍，可以拖动，也能用方向键细调、Home 最慢、End 最快。调速会同时影响说明停留和演示等待，重播和换课都保留这次的选择。暂停不消耗演示时间，继续就从当前环节接着来。

播放失败会显示原因，点「重试当前环节」重建独立演示并准备前置步骤，或点重播从头看。完成后有明确的完成提示，右侧可以重播或点「完成并退出」。退出或换课会清理旧演示帧，过期消息更新不了新课程。

演示用的是隔离的虚构资料，不读正式 IndexedDB/localStorage，也不写系统剪贴板或真实下载；完成记录表示你看完了，不表示亲手操作。备份教程里的虚拟文件只代替文件选择，预览、取消、确认仍走正式恢复处理器。正式页面必须选真实的 JSON 文件。

## 备份载入与恢复核对

备份区下载当前完整副本；恢复区按「选择文件 → 核对内容 → 确认恢复」排列。手机恢复区优先显示。选好文件立刻显示读取状态，完成后在同一区显示文件名、备份时间以及当前／待恢复数量对照，不用关掉重开窗口。

选文件只预览。确认会替换个人资料、草稿、回收站、显示设置和教程进度；先下载完整备份就能保住当前内容。换文件会重新读取，取消读取或预览都不会替换资料。损坏、格式不对、过新或超限的文件会在恢复区报错；旧读取结果不会盖住后来选的文件。

### 需求匹配 → 填材料 → 复制 → 回查来源

**作用与目的：** 把需求交给本地推荐，再亲手选模板、填材料、复制指令。

**适用时机：** 知道想做什么，希望系统推荐一条合适的方法。

**操作原理：** 输入先筛选主页，点匹配才出推荐；需求文字会带进一个参数，记得换成真实材料。

**准备条件：** 正式用要准备真实会议记录；练习只用虚构材料。

**学完会做什么：** 亲手从推荐进入模板，替换材料并复制，还能回查来源。

**操作边界：** 练习和正式工作区分开；先做真实动作，再看实际变化。

| 步骤 | 演示操作或观察 | 为什么做 |
|---|---|---|
| 1 | 在主页长搜索框输入「会议纪要」。 | 先看下面的筛选结果，这一步还没进需求导航。 |
| 2 | 点击搜索框右侧「匹配模板 →」。 | 点它会带着你的需求打开推荐列表；匹配按本地关键词算。 |

### 检查提示词 → 修改 → 保存旧版本

**操作原理：** 它只查正文里的文字线索，不打分、不联网；改动交给编辑器保存后才更新。

**准备条件：** 练习场提供一条虚构的会议复盘提示词；正式用时选自己的记录。

**学完会做什么：** 能看检查线索、改正文、复制清单、保存修改，并查看旧版本和差异。

### 收起、回收站与旧版本

**作用与目的：** 用几个好区分的操作整理提示词：不用的先收起，误删去回收站，改错找旧版本。

**适用时机：** 提示词越攒越多、想收起不用的，或发现误删、改错一条记录。

**操作原理：** 收起只是改状态；回收站保留整条和版本；恢复旧版本只改这一条。

**准备条件：** 练习场提供一条虚构记录和旧版本；筛选默认只看可用和草稿。

**学完会做什么：** 能收起和重新启用、删除到回收站与恢复，并查看和恢复单条旧版本。

**操作边界：** 永久删除要确认且不可从回收站恢复，本课只观察不执行。

| 步骤 | 演示操作或观察 | 为什么做 |
|---|---|---|
| 1 | 打开「我的工作区」。 | 整理自己的记录，用不到模板库的发布工具。 |
| 2 | 展开练习记录的「更多」。 | 次要动作集中显示，先读名称再操作。 |
| 3 | 点击「收起暂不用的」。 | 记录从可用列表收起，正文和旧版本都还在。 |
| 4 | 在状态筛选选择「已收起」。 | 收起的记录仍保留，用筛选就能找回。 |
| 5 | 再展开这条记录的「更多」。 | 已收起状态下会给出重新启用。 |
| 6 | 点击「重新启用」。 | 恢复可用状态；当前筛选只看已收起，它会暂时离开列表。 |
| 7 | 把状态筛选改回「可用和草稿」。 | 回到日常列表，核对记录还在。 |

## 常见卡点

| 现象 | 处理 |
|---|---|
| 收起后找不到 | 状态筛选选「已收起」，再进「更多 → 重新启用」 |
| 检查后原记录没变 | 检查只给线索；点「保存修改」后，还要在编辑器里保存 |
| 修改正文后清单消失 | 旧清单已失效，重新检查 |
| 收藏打开来源广场 | 这是原文收藏，保留署名，不是母模板副本 |
| 文件选完没有恢复 | 先在恢复区核对文件、时间和数量，再点明确的确认恢复 |
| 提示不是完整备份 | 单独导出的提示词通过导入文件追加，完整恢复用工作区 JSON |
| 找不到以前发布工具 | 本地个人版已移除，旧记录仍随完整备份保留 |
| 训练没有真实下载 | 练习用的是虚拟文件区；退出教程后再进行正式下载 |
