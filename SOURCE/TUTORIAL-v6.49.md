# AI Playbook v6.49 / P71 · 使用教程

打开新版 HTML，在任意主题点击同名的 **「使用教程」**。先读模块说明，知道操作有什么作用、什么时候需要、准备哪些材料、系统实际会改变什么，再开始练习。

本版有 17 个模块、204 个环节：169 个真实操作与 35 个观察环节。十项高级工具均有练习。无需一次学完；建议先读主界面，再学需求匹配与个人版本。

## 工作区归零与收藏的实际操作

本版本首次在正式浏览器打开，会把旧个人提示词、收藏、最近使用、草稿和随手记、回收站及本地治理运行记录归零；包括测试发布覆盖，母模板与来源原文不变。先保留归零前备份，显示偏好与教程进度也保留。之后重新打开不会再清空新增记录。归零发生在实际打开页面的浏览器，文件中没有内置私人数据。训练场跳过归零。

在我的工作区可点「导出归零前备份」查看旧数据；通过「恢复备份」恢复会带回旧验证记录，并覆盖当前数据，先导出当前工作区。普通工作区备份现在也包含治理记录与收藏关系。

| 位置 | 如何收藏与整理 | 作用 |
|---|---|---|
| 主页每张模板卡片 | 点☆ 收藏；★ 已收藏再点可取消 | 无需打开详情，收藏不会触发打开工作台 |
| 模板详情顶部 | 点收藏或已收藏 | 与主页按钮同步，在手机也能看到 |
| 来源广场列表与详情 | 点收藏或已收藏 | 保存此发布记录入口，保留署名，不变成母模板或个人提示词 |
| 旧模板档案详情 | 点收藏 | 找回旧档案，正文仍保留 |
| 我的工作区 → 收藏 | 打开 / 派生个人版 / 删除收藏 | 标明对象类型；派生须编辑并保存；删除只移除关系 |
| 我的工作区 → 最近使用 | 每条记录点删除 | 清除该访问记录，模板仍在，再打开会重新记录 |

同文不同发布记录可以分别收藏，不合并署名。收藏只保存入口，不保存本次填写的参数；重要方法要保存个人版本。写入失败会提示重试，不假装已成功。

## 先明白系统在做什么

系统在本页检索和组织提示词，参数里的 [变量] 是每次变化的材料；填写后会组装完整指令。复制指令，粘贴到自己使用的 AI 工具，才会得到模型回答。质量指标、匹配程度、来源署名与模型效果是不同概念，仍须核对真实输出。

个人提示词保存你自己的方法，编辑保存会留旧版。候选接受只是评审决定；内容发布、版本批次、版本登记、预览版和稳定版指针是独立记录。本地稳定指针不等于已经交付新的离线 HTML。

## 按真实界面学，不跳过中间步骤

| 路径 | 真实操作顺序 | 注意 |
|---|---|---|
| 关键词筛选 | 在长搜索框输入 → 看主页筛选结果 → 亲手点卡片 | 此路径不点击匹配模板，也不打开需求对话 |
| 需求匹配 | 输入 → 点匹配模板 → 看推荐与适配稿 → 亲手点进入模板继续填写 | 本地匹配会预填一句需求，它不是完整会议材料，必须核对并替换 |
| 来源回查 | 点来源页 → 点具体摘录 → 核对署名与原文 → 沿广场回链查看记录 | 同文记录不一定都关联母模板，依据实际按钮继续 |
| 页码跳转 | 修改来源页码 → 检查输入 → 在页码框按回车 | 输入数字不会自动跳页；检查输入也不会替你提交表单 |

真实工作台默认已在「02 参数」，课程会说明并观察这个状态，不要求重复点击来制造步骤。带练中的每个跳转都来自真实按钮或表单处理器。只有主动选择单环节专练时，系统会明确提示自动准备前置条件；准备过程仍走实际处理器，不计为亲手完成。示范也只展示真实流程，不记你的完成。

## 一个输入环节有四个阶段

1. **复制示例**：右侧练习文字框与复制按钮高亮，注释说明这段材料的用途。点复制，再亲手粘贴到左侧指定字段。清空字段或选择下拉项时不需要复制。
2. **填写或选择**：左侧真实控件高亮，旁边解释该参数或选项为什么需要。示例不会自动替你填入。
3. **检查输入**：有真实输入后，右侧检查按钮才高亮，并解释它只核对本步输入与本地状态，不发送给 AI、不自动发布。点击后右侧高亮与注释消失；不符合条件则读反馈重试。
4. **观察变化**：成功后，左侧高亮实际变化的记录、状态或内容。看清注释，再点「我已看到变化，继续」，不会按定时器自动越过结果。

观察环节只介绍界面或入口，明确不代点业务按钮；读懂后点「我看清楚了，继续」。独立挑战撤掉下一操作提示，填写后可按 Tab，操作成功后仍需要核对结果。使用提示或示范会记作使用帮助。

## 提示、窗口与结束

左侧注释优先放在目标旁，不能与当前操作区域重叠；空间不足时移到练习区上方专用说明栏。右侧说明可以滚动，调整窗口大小后布局随窗口实际宽度切换。教程默认最大化；桌面可还原、拖动标题和缩放边框，教程最小高度与控制器一致。教练区域随窗口实际高度调整，矮视口可滚动导航，相关复制/检查/继续按钮会自动滚到教练区可见处。窄屏使用上下布局，手机使用全屏。

每套模块结束会显示明确的「本模块教程已完成」，清除全部操作高亮与弹出注释。点 **「完成并退出」** 返回正式主页。单环节只显示该环节完成，不冒充完成整套流程。示范结束也清除提示，关闭示范后回自己的练习。

练习会沿用当前主题场景、明暗与手机模式偏好；这些只是显示设置。训练使用隔离的虚构个人与治理记录；原始母模板和来源资料沿用内置数据。质量退步样例明确移除部分来源字段以供观察，正式库不会改变。训练复制/导出只核对内部内容，右侧复制仅复制虚构示例。正式工作请退出教程，用自己的材料复做；重要资料先导出备份。

## 推荐学习顺序

| 顺序 | 模块 | 学会什么 |
|---|---|---|
| 1 | 主界面与每个按钮的用途 | 辨别检索、资产、来源、日志、帮助和设置入口 |

## 各模块的目的与逐步清单

### 主界面与每个按钮的用途

**作用与目的：** 认清主页每个入口，能判断自己的任务从哪里开始。

**适用时机：** 初次打开、不知道从哪里开始。

**操作原理：** 主页是导航与检索；阅读介绍不会替你执行业务操作。这个模块逐个高亮入口并解释作用，点右侧确认继续。

**前置条件：** 不需要个人记录；此模块只观察说明，不代点按钮。

**学完的结果：** 能区分搜索、需求推荐、个人资产、来源与设置入口。

**边界：** 训练与正式工作区隔离；示范与自动准备不计为亲手完成。本模块仅观察入口，实际执行另选操作课程。

### 需求匹配 → 填材料 → 复制 → 回查来源

**作用与目的：** 把需求提交给本地推荐，再亲手选模板、填写材料、复制指令和核对来源。

**适用时机：** 知道想完成什么，希望系统推荐适合的方法。

**操作原理：** 输入只筛选主页；点击匹配才显示推荐。需求导航会把需求文字带入一个参数，但它不是完整会议材料，必须核对并替换。

**前置条件：** 正式操作须准备真实会议记录；训练只使用虚构记录。

**学完的结果：** 亲手从推荐进入模板，替换材料并复制；能回查三条来源。

**边界：** 训练与正式工作区隔离；示范与自动准备不计为亲手完成。先做真实动作，再看实际变化；不能把完成训练当作模型效果或真实发布已通过。

| 环节 | 真实操作或观察 | 为什么这样做 |
|---|---|---|
| 1 | 在主页长搜索框输入「会议纪要」。 | 先看下面的筛选结果；还没有进入需求导航，也没有生成 AI 回答。 |
| 2 | 点击搜索框右侧「匹配模板 →」。 | 这是提交需求的真实按钮，会打开需求导航并显示本地推荐，不能直接跳到工作台。 |

| 8 | 观察「02 参数」：真实工作台默认已打开这里，无需重复点击。 | 选中状态表示当前页。下一环节直接填写材料，不把重复点击当作必要操作。 |

## 常见卡点

| 现象 | 正确处理 |
|---|---|
| 搜索后仍在主页 | 输入只是筛选；想进入推荐须点匹配模板或按回车 |
| 推荐后参数已经有文字 | 预填的是需求，不是完整材料；核对并替换 |
| 检查后还没有下一步 | 读反馈；成功后还要确认实际变化 |
| 右侧示例不会自动进入左侧 | 它用于复制练习；必须亲手粘贴或填写 |
| 下拉项没有示例复制框 | 直接选指定选项，检查后观察筛选或排序结果 |
| 页码填完还没变化 | 在页码框按回车提交，不能把检查输入当成跳页 |
| 同文记录没有关联模板按钮 | 此记录没有关联；沿真实同文回链找到确有按钮的记录 |
| 复检仍阻断 | 未补齐真实回滚事实；计划和复检都不是自动修复 |
| 看了示范却没完成记录 | 示范不计亲手完成，关闭后回自己的练习 |
| 单环节完成后还有其他步骤 | 只练了一个环节，完整模块需另做 |
| 提示进度未保存 | 可以继续练，但刷新可能丢失进度；确认浏览器允许本地保存 |
