# v6.46 / P68 高级工具中文界面

在「我的工作区」展开「高级工具」。十项入口仍沿用原来的工作流程，页面和相关弹窗的标题、说明、按钮、状态、提示及帮助改为中文。

| 原显示 | 当前显示 | 操作含义 |
|---|---|---|
| Dry Run | 预演 | 查看执行计划并保存预演记录，必要时生成待审事项 |
| Execute | 执行 | 满足门槛后可能推进版本通道 |
| Gate | 检查门槛 | 发布前必须核对的条件 |
| AUTO | 允许继续 | 当前策略允许推进，仍需核对目标 |
| REVIEW | 需要审查 | 先由人核对证据并作出决定 |
| BLOCK | 暂不可发布 | 先处理当前阻断 |
| Preview / Stable | 预览版 / 稳定版 | 当前浏览器的版本通道指针 |
| Override | 规则例外 | 有记录的例外申请与审批 |
| Pending / In Review | 待审查 / 审查中 | 人工审查事项当前状态 |
| Changes Requested | 待补充修改 | 需要补资料或修改后再审查 |
| Approved / Rejected | 已批准 / 已驳回 | 已有人工决定 |
| Resolved | 已处理 | 决定或修复已经记录为完成 |
| Re-check | 复检 | 检查对应阻断是否已解决 |

旧记录通过显示映射呈现中文，不改写原状态值。模板原文、署名、来源、版本号、记录编号、工作区备份及发布内容包的内部格式继续保留。

日常创作可以继续使用个人提示词、收藏、最近使用、随手记和回收站。需要维护系统母模板时再进入高级工具；具体操作可以开启主界面帮助，点击相关控件查看用途、步骤和影响。

本版同步了教程、开发日志和版本信息。模型效果评测、真实候选模拟、完整整版内容回滚等功能不在本次中文化改动范围。
