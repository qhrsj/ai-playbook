# v6.45 / P67 批量导入操作说明

本说明根据恢复出的实际代码补建；网页内教程和帮助仍是上传 v6.45 文件里的原内容。

1. 在主页打开「导入」，选择 Excel、CSV、TSV、TXT、Markdown 或 Prompt JSON 文件。可以一次选择多个文件；文件只在当前浏览器读取。
2. 表格先选工作表，检查是否包含当前表，以及表头的原始行号（没有表头填 0）。默认包含每个工作簿第一个非空工作表，其他表需手动勾选包含。
3. 核对列映射：正文列必选；标题、分类、标签、署名发布者、出处和外部条目 ID 可选。署名和来源会随个人记录保存。
4. TXT/Markdown 默认整篇一条，可按单独一行 `=== PROMPT ===` 或 Markdown 一级标题拆分。代码块中的内容和普通分隔线不作为拆分边界。
5. 查看每页最多 15 条的预览，按需展开完整正文。正文重复和同名不同正文默认不勾选；手动勾选后创建独立记录，不覆盖旧条目。修改映射或拆分方式会重新生成勾选。
6. 点击「确认导入」并等待保存成功，然后到「个人模板」或「我的工作区」查看与编辑。保存失败时预览保留，可重试；尚未确认的读取可取消，不改变已保存记录。

## 文件与容量边界

- 单文件最多 20 MB，本批文件合计 40 MB，最多 10000 条。Excel 还有解压总量、列数和工作表数限制，以避免过度解析。
- 加密工作簿需先解除密码。不能直接把工作区备份当提示词文件上传，备份恢复入口在「我的工作区」。
- 读取上限与浏览器可存空间分别判断；读取成功不代表必然能保存同等容量。
- 旧个人数据由启动流程迁移到本地数据库。更换浏览器或文件路径前，用工作区导出完整 JSON 备份；恢复会替换个人数据。
