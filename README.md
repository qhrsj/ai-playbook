# AI Playbook · AI 提示词&skill库

一个**纯本地、单文件、离线可用**的 AI 提示词工作系统：把策展过的提示词模板、原始发布语料和 Agent Skill 装进一个 HTML 文件，双击即用。

## 网页功能介绍

### 模板库（主页第一栏）
- **79 张策展母模板**，覆盖写作、开发、营销、学习、生活等 18 个分类，6 套界面主题
- 每张模板走统一四步工作台：**概览 → 填参数 → 看成稿 → 查来源**
- 「匹配模板」：用大白话描述你的任务，本地规则推荐合适的模板
- 分类选项卡 + 分栏搜索，快速缩小范围

### Skill 广场（主页第二栏）
- **3115 个 Agent Skill**（来自炉子广场），与提示词分栏存放、分开搜索
- 每条保留署名作者、来源、入口文件、文件数与大小
- 点击「查看正文」阅读完整 SKILL.md，可一键复制（请保留署名）

### 提示词广场（导航栏）
- **1612 条原始发布记录**，逐条保留署名作者、来源、作者主页与完整正文
- 支持检索、分类、排序、跳页浏览；可收藏、可另存为自己的提示词

### 我的工作区
- 个人提示词：新建、编辑、历史版本、复制派生
- 收藏 / 最近使用 / 随手记草稿 / 回收站
- 检查提示词（结构体检）与备份恢复（导出/导入 JSON）

### 使用教程（导航栏）
- **33 门交互式课程**：操作地图 → 跟导览看一遍 → 亲手练
- 每一步可暂停、可重放，做对才继续；进度自动记录

## 快速开始

1. 下载 [`dist/index.html`](dist/index.html)（约 47 MB，无需安装任何东西）
2. 用 Chrome / Edge 双击打开即可
3. 所有个人数据只存在你自己的浏览器里，**不联网、不上传**；换浏览器前记得用「备份与恢复」导出

## 内容来源与致谢

「提示词广场」与「Skill 广场」的内容均来自 [炉子广场](https://luzi.top)，**逐条保留了原作者的署名、来源与主页信息**；复制使用时请一并保留署名，尊重原创。
